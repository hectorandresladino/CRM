# Data Processing Addendum (DPA)

**Last updated: 2026-08-29**

## 1. Purpose

This DPA supplements the Terms of Service and governs the processing of personal data by CRM SaaS on behalf of its customers ("Data Controllers").

## 2. Roles

- **Data Controller**: The customer organization that determines data processing purposes
- **Data Processor**: CRM SaaS, acting on behalf of the Data Controller
- **Data Subjects**: Individuals whose data is processed (contacts, leads, customers)

## 3. Processing Details

| Item | Description |
|------|-------------|
| Categories of data | Contact info, communication records, business transactions |
| Purposes | CRM, sales, marketing, service, billing |
| Duration | While subscription is active + 30 days |
| Recipients | Payment processors, communication providers, cloud infrastructure |
| Location | Colombia, USA, EU |

## 4. Data Controller Obligations

- Obtain consent from data subjects
- Ensure data accuracy
- Provide privacy notices
- Comply with GDPR, CCPA, and local laws

## 5. Data Processor Obligations

- Process data only per Controller's instructions
- Maintain confidentiality
- Implement appropriate security measures
- Notify Controller of data breaches within 72 hours
- Assist with data subject requests
- Delete data after termination (30 days)

## 6. Sub-Processors

| Sub-Processor | Purpose | Location |
|---------------|---------|----------|
| Stripe | Payment processing | USA |
| Wompi | Payment processing (LATAM) | Colombia |
| PayU | Payment processing | Netherlands |
| Meta/WhatsApp | Messaging | USA |
| Cloud Provider | Hosting | USA/EU |

## 7. Data Breach Procedure

1. Detection and assessment (within 24h)
2. Notification to Controller (within 72h)
3. Containment and remediation
4. Post-incident review and improvements

## 8. Data Return and Deletion

Upon termination:
- Controller may export all data (30 days)
- Processor deletes all data after 30 days
- Backup tapes securely destroyed after 30 days

## 9. Audit Rights

Controller may audit Processor's compliance once per year with 30 days notice.
